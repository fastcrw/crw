CRW — open-source web scraper & crawler (Firecrawl-compatible)

Docs at docs.fastcrw.com. Hosted API at https://api.fastcrw.com. Self-hosted at http://localhost:3000. Five endpoints: /v1/search, /v1/scrape, /v1/crawl, /v1/map, /v1/extract.

Quick: copy this and run

Auth (hosted only): Authorization: Bearer $CRW_API_KEY. Self-hosted (http://localhost:3000) needs no header.

Body: { "query": string, "limit": number (default 5, max 20), "lang"?: "en", "tbs"?: "qdr:d|w|m|y", "sources"?: ["web"|"news"|"images"] }

Python (stdlib only — defaults to hosted, fails loudly if key is missing)

#!/usr/bin/env python3
"""Search CRW and print top results as JSON."""
import json, os, sys, urllib.request

API_KEY = os.environ.get("CRW_API_KEY")
# Default to the hosted API. Self-hosting? Set CRW_API_URL=http://localhost:3000
BASE = os.environ.get("CRW_API_URL", "https://api.fastcrw.com")
URL = f"{BASE}/v1/search"

headers = {"Content-Type": "application/json"}
if API_KEY:
    headers["Authorization"] = f"Bearer {API_KEY}"
elif BASE.startswith("https://api.fastcrw.com"):
    sys.exit("error: CRW_API_KEY is required for the hosted API. "
             "Get one at https://fastcrw.com (1000 free credits) "
             "or set CRW_API_URL=http://localhost:3000 to self-host.")

req = urllib.request.Request(
    URL,
    data=json.dumps({"query": "renewable energy trends 2024", "limit": 3}).encode(),
    headers=headers,
    method="POST",
)
with urllib.request.urlopen(req) as r:
    body = json.loads(r.read())  # body == {"success": true, "data": [...]}

# Results live under body["data"]. Each row has `title`, `url`, `snippet`,
# `description`, `position`, `score`, `category` — print the LLM-ready subset.
print(json.dumps(
    [{"title": x["title"], "url": x["url"], "snippet": x["snippet"]}
     for x in body["data"]],
    indent=2,
))
# Run with: python3 search.py  (file is python3-only — no `python` alias needed)

CLI (one-shot LLM-ready output)

The crw CLI projects directly to the title/url/snippet schema with --json --fields — no jq reshape needed:

# Install: brew install fastcrw/crw/crw  (or: cargo install crw-cli)
crw search "renewable energy trends 2024" --json --fields title,url,snippet --limit 3

# Available fields: title, url, description, snippet, position, score, category
# --json is shorthand for --format json (also accepts --format text|markdown)
# Self-hosted: no auth. Hosted: export CRW_API_KEY=crw_live_...

Pergamon

Cloud only (fastcrw.com). Self-hosted instances have no provider registry and no credit wallet.

Overview

Pergamon is the fastCRW data API. It puts official APIs, public registries and statistics offices behind the same key, the same credit wallet and the same error shape as the rest of fastCRW.

The name is the library that rivalled Alexandria. Alexandria cut off its papyrus supply to starve it; Pergamon invented parchment instead, which is where the word comes from.

You do not learn a provider's quirks. You read the catalog, call a capability, and get back a normalized envelope with the data and the provenance you need to use it legally.

Browse what is live at fastcrw.com/pergamon.

The two endpoints

GET https://api.fastcrw.com/v1/data                          the catalog, free
GET https://api.fastcrw.com/v1/data/{provider}/{capability}  the data, 1 credit

Both take the standard header:

Authorization: Bearer YOUR_API_KEY

Discover what is available

The catalog is free to call and is generated from the same registry the API serves, so it is never out of date.

curl https://api.fastcrw.com/v1/data \
  -H "Authorization: Bearer YOUR_API_KEY"
{
  "success": true,
  "credits_used": 0,
  "providers": [
    {
      "slug": "npm",
      "name": "npm Registry",
      "description": "Package metadata from the public npm registry...",
      "category": "Developer",
      "country": null,
      "licence": "Public npm registry metadata, served without a key...",
      "licence_url": "https://docs.npmjs.com/policies/open-source-terms",
      "attribution_text": "Source: npm registry",
      "commercial_use": true,
      "redistribution": false,
      "capabilities": [
        {
          "slug": "package",
          "description": "Full packument for a package: every version, dist-tags, maintainers.",
          "path": "/v1/data/npm/package",
          "required_params": ["name"],
          "optional_params": [],
          "credits": 1
        }
      ]
    }
  ]
}

required_params and optional_params are the whole contract. There is nothing else to know about a capability before calling it.

Call a capability

curl "https://api.fastcrw.com/v1/data/npm/package?name=react" \
  -H "Authorization: Bearer YOUR_API_KEY"

Every successful response has the same shape:

{
  "success": true,
  "provider": "npm",
  "capability": "package",
  "credits_used": 1,
  "request_id": "fP4Nxx4Urn-H06AxscbM_",
  "provenance": {
    "source": "npm Registry",
    "upstream_url": "https://registry.npmjs.org/react",
    "licence": "Public npm registry metadata, served without a key...",
    "licence_url": "https://docs.npmjs.com/policies/open-source-terms",
    "attribution_text": "Source: npm registry",
    "retrieved_at": "2026-10-11T16:44:02.117Z",
    "adapter": "rest",
    "cache_age_seconds": 0,
    "is_stale": false
  },
  "data": { }
}

data is the provider's own payload, passed through. We normalize the envelope around it, not the records inside it — so you keep every field the source publishes.

The provenance block

Field What it is for
source The provider's name, as it should be credited
upstream_url The exact URL we requested, so you can verify us
licence / licence_url The source's own terms, quoted
attribution_text The line to display wherever you show the data
retrieved_at When the body was fetched upstream
cache_age_seconds Seconds since that fetch. 0 on a live call
is_stale true when the body came from our cache rather than a live call

If a source requires attribution, attribution_text is how you satisfy it without hard-coding anything per provider.

Credits

One credit per call, flat, whatever the provider. The catalog endpoint is free.

Nothing is billed for a failure: if the upstream returns an error, times out, or answers with something unusable, the credit is refunded automatically and the response says so.

A cache hit is billed. The credit pays for the record; the cache buys you the latency. provenance.is_stale tells you which one you got.

Caching

Each provider carries its own TTL, and the licence sets it, not latency. Where a source permits retention we cache hard; where a source says responses may not be retained, the TTL is 0 and every call goes upstream. Each provider page under fastcrw.com/pergamon states its TTL.

Errors

{
  "success": false,
  "error": "Missing required parameter \"name\"",
  "request_id": "fP4Nxx4Urn-H06AxscbM_"
}
Status Meaning
400 A parameter is missing, too long, or not valid
401 Missing or invalid API key
402 Out of credits
404 No such provider or capability, or it is not currently enabled
429 Rate limited — see Rate limits
501 The provider needs your own upstream credential (not available yet)
502 The provider answered, but with an error or an unusable body
504 The provider did not answer in time

A 404 is deliberately indistinguishable between "never existed" and "switched off". Call the catalog to see what is live right now.

Why a 200 can still be a 502

Several official data sources answer 200 with an HTML error page, a WAF challenge, or an empty body. We treat the content type and the JSON parse as the real status check, so you get a 502 and your credit back rather than a page of HTML where a dataset should be.

Parameters and safety

Required parameters come from the capability's path; optional ones are an explicit allowlist. Anything you send that is in neither is dropped before the upstream call, and your values can never change which host is contacted — only what is asked of it.

Worked examples

# A package and its weekly downloads
curl "https://api.fastcrw.com/v1/data/npm/package?name=react" \
  -H "Authorization: Bearer $FASTCRW_API_KEY"

curl "https://api.fastcrw.com/v1/data/npm/downloads?period=last-week&name=react" \
  -H "Authorization: Bearer $FASTCRW_API_KEY"

# A Python project's releases
curl "https://api.fastcrw.com/v1/data/pypi/project?name=requests" \
  -H "Authorization: Bearer $FASTCRW_API_KEY"
const res = await fetch(
  "https://api.fastcrw.com/v1/data/npm/package?name=react",
  { headers: { Authorization: `Bearer ${process.env.FASTCRW_API_KEY}` } },
);
const body = await res.json();

console.log(body.data["dist-tags"].latest);
console.log(body.provenance.attribution_text); // display this
import os, requests

r = requests.get(
    "https://api.fastcrw.com/v1/data/pypi/project",
    params={"name": "requests"},
    headers={"Authorization": f"Bearer {os.environ['FASTCRW_API_KEY']}"},
    timeout=30,
)
body = r.json()
print(body["data"]["info"]["version"])
print(body["provenance"]["attribution_text"])

Asking for a source

The catalog grows by request. If a source you need is missing, tell us which one — including the URL of its API or its open-data page, which is what decides how quickly it can be added.

A source only appears in the catalog once someone has read its terms. If an answer is "not without a written agreement", it stays out rather than shipping quietly.
